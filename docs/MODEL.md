# 模型设计、接口与物理边界

## 来源与机械结构

机械依据为厂商 [agx_arm_urdf@a68b8e876a2c6fcb0ecee7a7943129e4d48dd864](https://github.com/agilexrobotics/agx_arm_urdf/tree/a68b8e876a2c6fcb0ecee7a7943129e4d48dd864) 的 `nero_description.urdf`、`nero_with_flange_description.xacro` 和 `nero_with_gripper_description.xacro`。冻结来源避免上游变化导致安装和机械参数无声变化；29 个源文件逐字节保留，路径、Git blob 与 SHA256 由 `SOURCE_MANIFEST.json` 索引。

展开 URDF 与 MJCF 包含 NERO 的 `base_link`、`link1..link7`、官方法兰、夹爪基座和两个手指，共 12 个实体部件。固定安装采用源变换：

| 安装关系 | 平移 xyz / m | 旋转 rpy / rad |
|---|---|---|
| world → base_link | 0, 0, 0 | 0, 0, 0 |
| link7 → flange_link | 0.031, 0, -0.0235 | -1.5708, 0, -1.5708 |
| flange_link → gripper_base | 0, 0, 0.006 | 0, 0, 0 |

该安装链属于这一来源版本；不采用其他夹爪资产的安装假设。总质量 5.12892366 kg 为源描述之和，其中 `link7` 的源质量为 0.001 kg。这些值的来源一致性已核对，尚无实机测量证明其物理准确性。官方仿真对照文件含不同质量、惯量和阻尼，因此不作为整套机械字段的替代来源。

## 关节与夹爪

状态顺序为 `joint1..joint7, gripper_joint1, gripper_joint2`，前七维为 rad，末两维为 m。

| 机械臂关节 | 源范围 / rad |
|---|---|
| joint1 | [-2.70526, 2.70526] |
| joint2 | [-1.74, 1.74] |
| joint3 | [-2.75, 2.75] |
| joint4 | [-1.01, 2.14] |
| joint5 | [-2.75, 2.75] |
| joint6 | [-0.73, 0.95] |
| joint7 | [-1.5707963, 1.5707963] |

源 `gripper` 是一个无质量、惯性、几何或子部件的虚拟命令关节，其范围为 `w ∈ [0, 0.1] m`。源 mimic 定义 `q1 = 0.5w`、`q2 = -0.5w`，手指范围分别为 [0, 0.05] m 和 [-0.05, 0] m。

MuJoCo 消去这个虚拟叶子，避免为非物理部件虚构惯性；保留两个实体手指自由度，以 `q2 = -q1` 的 joint equality 表达耦合，命令坐标可由 `w = 2q1` 恢复。实体运动学和质量等价，虚拟命令 TF 的移动不再单独显示。`w` 是来源命令坐标，不能直接解释为真实指尖净间距。

MuJoCo equality 是软约束，接触加载下允许有限残差。空载测试验证了当前配置的耦合误差范围；带载抓取尚未通过 0.2 mm 阈值。不能用静态设姿态时的零残差证明所有动态工况的刚性同步。

Joint 2 的另一个官方仿真文件范围为 [-0.261799, 3.31613] rad，与源 URDF 及官方 `nero.xml` 的 ±1.74 rad 不一致。十组对照 FK 未支持 90° 零点偏移解释。受控实验采用两者交集内的 [-0.2, 1.5] rad 命令区间；原 MJCF/URDF 限位不改，真实硬件有效限位未确认。冻结对照文件及哈希索引见 [references/manifest.json](../experiments/dynamics/references/manifest.json)。

## 质量、惯性与默认参数

各实体质量、惯性中心和完整惯性张量来自源描述。MJCF 使用显式惯性，完整张量经对称特征分解转为主惯量与主轴，编译后再重建张量独立核对；不从碰撞凸包体积推导机器人质量或惯量，也不为通过验证修改原张量。

缺失的机械阻尼、armature、摩擦损失使用引擎默认值。机器人接触摩擦、接触求解和 equality 数值参数同样包含引擎默认；它们不是厂商测得的接触或传动参数。受控模型保留参考模型的这些值，另明确设置时间步、重力、积分器与执行器。

## 可视与碰撞几何

可视 DAE 按场景变换展开为带 UV 的 OBJ，保留三角面。每个材料图元通过 UV 指向 PNG 调色板中的源 diffuse 色块，保留部件的局部多色、面板及由材料表达的标识；12 张调色板采用 8 bit 颜色量化，总体积约 1 KiB，不依赖原先的 JPG 集合。光照与材质渲染不要求和 COLLADA 像素一致；原 DAE 材料仍保留。未绑定材料的图元使用中性灰，其三角面保留。

碰撞 STL 按精确相同坐标分连通分量，再逐分量生成凸包。这样可保留分离结构的几何分布，同时使用 MuJoCo 的凸网格碰撞。没有容差焊接、源拓扑修补、移位或挤出：NERO 连杆 51 个、法兰 3 个、夹爪基座 4 个、每指 2 个，共 62 个。

每指还有四个平面标识三角面，其顶点完全包含于对应实体凸包，来源面记录归入该凸包，避免为平面伪造厚度。所有源面归属、顶点数、凸包体积与闭合源体积比保存在 [mesh-conversion.json](../reports/mesh-conversion.json)；非闭合源分量的体积比为 null。

凸包会填充凹部和空腔。保留源顶点、全部面归属和包围边界，仍不能证明接触表面与原三角网格一致。可视 geom 的碰撞 mask 为 0/0，碰撞 geom 为 1/1；引擎还存在同 body、焊接 body 和父子关系的默认过滤。

## 相邻碰撞过滤

纯静态参考没有显式 exclude。其凸包 `base_link/link1` 在已检查姿态中约有 5 mm 重叠，在积分诊断中产生最高约 1.46×10⁶ N 的内部法向反力。相关法向 Jacobian 接近零，重叠不能通过这组实体自由度消除。抽样代理边界距原底座 STL 表面约 17.75 mm，支持凸包填充中空结构的解释；无符号表面距离不等于真实材料穿透证明。

受控派生配置只排除 `base_link/link1`。依据包括固定安装关系、上述数值诊断、官方两个 MuJoCo 模型的同对 exclude，以及 SRDF 的 Adjacent 声明。各 5000 次真实步的过滤前后对照保持其余机械、几何、接触、执行器和 equality 数组及全局参数相同，排除后该对异常内部反力消失。

此处理使受控实验能在明确的碰撞近似边界内执行，代价是失去这两个 body 间的接触检测；它不是任意关闭自碰撞的许可，也不能证明真实机器人不存在该处机械接触。原始参考模型、源网格及其余碰撞对保持不变。运行配置见 [base-filter-approval.json](../experiments/dynamics/base-filter-approval.json)，原始对照证据入口见 [验证说明](VALIDATION.md)。

## 受控模型与控制接口

`mjcf/nero_gripper.xml` 为无执行器的静态参考，`nq=nv=9, nu=0, neq=1`。`experiments/dynamics/controller.py` 从它运行时派生控制模型，复用相同网格和机械字段，加入九个限力 affine general actuator；仅在指定配置中加入上述相邻过滤。空载配置 `nu=9`，加入自由立方体后整体 `nq=16, nv=15`。派生模型不是另一套权威机械定义。

用户输入为 8D 绝对关节位置目标 `[q1..q7, w]`，内部目标为 `[q1..q7, w/2, -w/2]`。`Controller.validate()` 拒绝错误形状、非实数、非有限值和越界目标；`set_target()` 在有效输入后更新请求，无效请求不替换最后有效目标。

执行器输入为比例位置反馈加模型 `qfrc_bias` 前馈，速度反馈由原生 actuator bias 提供。输入与总执行器力分别受限；驱动依赖真实 `mj_step`，执行循环不写 `qpos`，不施加 `qfrc_applied/xfrc_applied`。初始化、scratch IK 与离线回放的状态设置具有独立用途。

| 参数 | 当前受控配置 | 来源与含义 |
|---|---|---|
| 时间步 / 积分器 | 0.001 s / implicitfast | 显式仿真选择 |
| 目标 / 反馈频率 | 100 / 1000 Hz | 调用循环设置 |
| 机械臂 KP | [160,160,160,80,40,40,30] N·m/rad | 仿真增益 |
| 机械臂 KV | [12,12,10,6,3,3,2] N·m·s/rad | 仿真增益 |
| 每指 KP / KV | 800 N/m / 8 N·s/m | 仿真增益 |
| 力限 | 每轴 100 N·m；每指 10 N | 源 effort 描述，非实测输出保证 |
| 目标速率 | 0.2 rad/s；夹爪命令 0.03 m/s | 仿真目标限速，非源 velocity 限值 |

完整配置见 [config.json](../experiments/dynamics/config.json)。接口提供关节位置控制；未提供笛卡尔 OSC、实机驱动、相机标定或特定学习框架适配器。

## 验证的含义

来源一致性、静态正确性、空载控制、物理抓取和实机保真度分别声明。静态核对覆盖 11 个有限姿态，不代表全工作空间；几何核对阈值 1 µm 用于编译浮点误差，不是碰撞真实性标准。空载控制覆盖指定 21 阶段动作，不证明所有加载工况稳定。抓取仍实验性，接触根因及硬件一致性未验证。最新测试范围与原始证据索引见 [VALIDATION.md](VALIDATION.md)。
