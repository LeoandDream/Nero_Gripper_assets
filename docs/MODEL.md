# 模型依据与边界

机械字段来自锁定提交的 `nero_description.urdf`、`nero_with_flange_description.xacro` 和 `nero_with_gripper_description.xacro`。官方法兰安装变换、夹爪安装变换、质量和惯性均采用该版本，未套用旧DH116资产的安装假设或惯性。实际部件的原完整惯性张量以NumPy特征分解转换为主惯量与主轴，MuJoCo编译后再独立重建张量核对；没有改变张量以满足验证。

## 虚拟开合关节

源URDF有10个非固定关节：NERO7、空 `gripper_link` 上的命令关节 `gripper` 和两个实体手指。命令关节没有质量、几何、惯性或子部件；源mimic为 `q1=0.5*w`、`q2=-0.5*w`。

为了避免给这个非物理叶子虚构惯性，MJCF保留全部12个实体部件，消去虚拟叶子和关节，保留两个手指自由度及一个 `q2=-q1` joint equality。静态姿态仍按源命令设置，`w=2*q1`可恢复命令坐标。该映射对实体部件的运动学和质量等价；没有声称保留空命令TF帧的移动，也没有验证软约束在动力学积分中的跟踪误差。

URDF中的effort/velocity限值原样留在URDF与接口契约中。模型没有actuator；没有把厂商描述中的限值当作已测得的真实驱动能力，也没有新增kp/kv、摩擦系数或机械阻尼。URDF缺失的机械阻尼、armature和摩擦项使用引擎默认，默认值不是硬件测量。

## 可视与碰撞

可视DAE按场景变换展开、保留全部三角面，转换成MuJoCo可用OBJ。按用户清理贴图的要求，每个部件使用源diffuse材料中三角面面积占比最大的颜色作为直接RGBA材质，不生成或依赖外部贴图。局部多色和标识配色被简化；原始DAE及原材料记录仍保留，不能将当前配色视为完整原厂外观。link2和link5各有一个未绑定材料的图元，原材料记录使用中性灰默认色；这些图元的三角面未删去。

碰撞STL按精确相同顶点坐标分连通分量，无容差焊接、源拓扑修补、部件删除或挤出。每个实体分量派生凸包：NERO连杆51个、官方法兰3个、夹爪基座4个、每个手指2个，共62个。两个手指各有4个平面标识三角面，全部顶点已在对应实体凸包内；将其归入该凸包的来源记录保留，几何并入没有加厚。

所有源面的分量归属、顶点数、凸包体积与可用的闭合网格体积比见 `reports/mesh-conversion.json`。对非闭合源分量，体积比明确为null。凸包体积变大可能来自空腔/凹部填充，不能用“源顶点和包围边界相同”证明接触表面同一。

没有 `<contact><exclude>` 或任意Never矩阵。MuJoCo自身仍有同body、焊接body及父子body的默认过滤；这不等于所有实体之间均检测接触。11个有限姿态中观测到base_link/link1约5mm的代理重叠，未通过移位或屏蔽消除；源三角面上的真实交会与这些近似接触的对应关系尚未在本包验证。以后接入控制前应处理这一已知接触问题。

## 验收含义

`PASS_STATIC_EQUIVALENCE` 表示已检查的实体字段、11个姿态的源FK和几何包围边界在报告阈值内一致。几何阈值1e-6m用于float32网格编译误差，不是碰撞真实性或实机精度标准。所有检查仅 `mj_forward`，时间为0，物理积分、策略动作、示教、训练均为0。

尚未验证：全工作空间、自碰撞真实性、碰撞分块在任务接触上的精度、动态mimic和控制稳定性、抓持、相机标定及真实硬件性能。
