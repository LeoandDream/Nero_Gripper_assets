所有129个原薄体均不要求保留独立身份；A/B功能必须由新的、达标的实体承接，C身份不再单独出现。没有为薄体设置尺度豁免。

## v2冻结预算与target surface

权威[protocol JSON](nero-gripper-v2-fidelity-protocol.json)绑定输入、分类产物和脚本SHA，完整列出37个源区域及2086个源三角片的tier规则。

| Tier | 外扩/内缩或局部简化预算 | 其它约束 |
|---|---|---|
| A：关键工作面、tip/ramp/shoulder、主要操作侧壁 | 双向表面距离各≤0.01mm | 轮廓≤0.01mm，法向≤0.05°；连续证书间隙≤0.001mm |
| B：宏观外壳、背袋、root及保护孔槽 | 双向表面距离各≤0.05mm | 轮廓≤0.05mm；保留方向、邻接与连通性，不逐facet复刻法向；证书间隙≤0.005mm |
| C：指定微缝/装配细节 | 可吸收的局部缝宽/法向细节厚度≤0.1mm；材料集合变化距离≤0.05mm | 不按旧C外露面做Hausdorff；A/B及保护空区优先，不能填大孔/整袋 |

预算继承原10/50/100µm尺度，依据源格式约97.2nm表示差异及原1mm穿透验收尺度，没有使用MuJoCo或抓取结果。**每个runtime凸实体最大内切球直径仍须≥0.1mm**，所有tier无豁免；该限制不表示“小于0.1mm的void可删除”。

表面域在v2几何前固定：

1. main/tip/ramp/shoulder、前层外缘、主要背体外侧壁为A；宏观背体/root及指定孔槽边界为B。
2. `thin_inner_layer_back_interface`及`backing_inner_interface`的装配微缝外露子域为C，内部closure本来就不是target。四安装凹座从源孔口沿y向内0.1mm的collar为B，更深的安装细节表面可为C；整个盲凹座的void/depth仍受B保护。深孔C表面退休不等于允许填孔。
3. Hausdorff类指标只对固定的A/B参考target与对应实际runtime外露面双向执行。消失的C微缝没有“必须在新外露面50µm内找到”的要求；仍保留的C深部面以材料/void规则检查。
4. 不能按结果改tier，也不能整族屏蔽mixed实体。新外露封口或填缝口若接到宏观外壳，继承相邻更严格的A/B；前向C排除须有预冻结C源域映射、位于其0.05mm邻域内且不占A/B/保护孔口边界。不得留下无归属的新外表面。
5. 未来验收必须使用认证的实际union外露面；当前provisional提取网格和有限采样不能代替连续证书。本轮不实施该几何验收。

## 必须保留的真实空区

以下全部列入B protected void，若邻接A轮廓则执行更严格A约束；不根据未知紧固件用途或当前cube尺寸删去。

| 结构 | 冻结义务 |
|---|---|
| 两个0.15mm侧通道 | 连续保留；每侧壁偏移≤0.05mm；每源截面净宽≥源净宽−0.10mm（名义剩余约0.05mm），禁止封口 |
| 大背袋 | 袋口、底面、侧壁、根隔墙及开放连通性保留 |
| 五个主要背体孔 | 四纵孔及一侧孔的入口/出口和通路保留 |
| 四安装凹座 | 孔口、0.1mm入口collar、盲腔和深度保留；深部facet身份可退休 |
| 中央贯孔 | 贯通路径和两端开口保留，不封成盲孔 |
| Root slot | 开口、底/侧壁及根部轮廓保留 |
| 主要缺口 | 中央根缺口及左侧非对称缺口保留；主工作面轮廓执行A预算 |

一般void规则：保留源空区向内侵蚀0.05mm后的连通芯、入口/出口关系和盲腔深度（偏差≤0.05mm）；不连通原本独立的void，不断开必须保留的通路。C最大缝宽规则不能覆盖这些明确保护项。
